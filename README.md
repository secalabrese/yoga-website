# Beginner Yoga Website

A multi-page informational website developed as a final project for an introductory college web development course. The website introduces beginners to yoga through pose guides, educational resources, and multimedia content.

## Live Website

[View the Beginner Yoga Website](https://secalabrese.github.io/yoga-website/)

## Project Overview

This project was designed to demonstrate foundational web development skills using HTML and CSS. The goal was to create an accessible, organized, and visually consistent website that allows visitors to explore beginner yoga information.

The project included preliminary planning, wireframe development, color palette selection, website construction, and testing.

## Technologies Used

- HTML5 — Page structure, navigation, forms, and multimedia integration
- CSS3 — Styling, layout, typography, and visual consistency
- GitHub Pages — Website hosting and deployment

## Website Features

- Three interconnected HTML pages
- Navigation between website sections
- Beginner yoga pose descriptions and illustrations
- Educational resources and embedded multimedia
- Audio integration
- HTML contact form using `mailto:`
- Consistent styling through an external CSS stylesheet

## Design and Development Process

Before developing the website, I created wireframes to plan the layout and organization of each page. I also selected a color palette to establish a consistent visual design.

The website was then developed using HTML and CSS, with an emphasis on organizing content, implementing navigation, incorporating multimedia, and maintaining consistency across pages.

The original wireframes and color palette are included in this repository to document the planning process.

## Project Context

This website was completed as an academic project while learning introductory web development concepts. It represents my foundational experience with HTML, CSS, website structure, and front-end development.
